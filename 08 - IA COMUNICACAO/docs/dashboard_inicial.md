# Dashboard Inicial - IA Comunicacao

## Objetivo

Criar a primeira dashboard do modulo para enxergar rapidamente:

- sentimento geral
- mensagens criticas
- palavras mais frequentes
- conversas com mais volume
- eventos recentes

## Blocos da tela

### 1. Grupos monitorados

Lista com:

- nome do grupo
- status ativo ou pendente
- primeira captura
- ultima captura

### 2. Mapa de palavras

Ranking dos termos mais citados:

- total geral
- por grupo
- destaque de termos criticos

### 3. Sentimento geral

Leitura consolidada com:

- percentual positivo
- percentual neutro
- percentual negativo

### 4. Resumo diario por grupo

Bloco textual com:

- resumo do dia
- palavra-chave principal
- urgencia
- sentimento do grupo
- resumo persistido quando o lote diario ja tiver sido gerado

### 5. Base futura para audio

Secao reservada para:

- transcricao de audio
- processamento de reunioes
- notas de voz
- uploads manuais

## Regra visual

Esta tela nao deve parecer uma dashboard generica.

Ela precisa ter leitura rapida e clara de risco, recorrencia e contexto.
